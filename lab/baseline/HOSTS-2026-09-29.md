# Matched-output baseline, two hosts (2026-09-29)

Same harness: `cargo bench --bench baseline`. Not Criterion. 4 warmup
runs, 20 measured reps, median, p95, bootstrap 95% interval of the
median (1000 resamples inside the harness). `profile.bench`, thin LTO,
codegen-units 1. Preflight is `syom::decode_cmp::run_preflight`. A peer
is timed only when the preflight calls it comparable.

Source is the working tree on top of `4aa2e715`, 223 dirty paths, not a
clean commit. rustc **1.97.1** (`8bab26f4f`) on both hosts. Peers:
rusty_aac 0.5.0, oxideav-aac 0.1.7, symphonia 0.6.1. libavcodec and
FDK are not linked.

| host | pin | placement |
|---|---|---|
| Linux x86_64 | AMD Ryzen AI 9 HX 370, governor `performance` | `taskset -c 0` |
| macOS 26.1 arm64 (25B78) | Apple M1 Pro, 10 threads, 16 GiB | no `taskset` |

Raw rows: `runs/2026-09-29-linux-x64-baseline.txt`,
`runs/2026-09-29-macos-arm64-baseline.txt`, plus the preflight logs
beside them. The 2026-09-14 table in `BENCH.md` is an older tree
(LC M4A there is 11264 samples; this tree presents 11025).

## Encoder bytes

On the Mac, `cargo test --lib` of the committed-fixture encoder checks
passed (11 tests, including `encoder_goldens_match_auto_and_scalar_fft`).
The SSE2-only test is x86_64-only and did not run there. The same checks
already pass on this Linux host.

The bench's own encode cells are not that fixture. They encode the
host's decode of `sine48.adts`. Mono landed on the same size on both
hosts (ADTS 5035 B, 142413 bps). Stereo differed by one byte (Linux
5025 B / 142125 bps, Mac 5024 B / 142096 bps). Both are about 11% over
the 128 kbps request on this short tone, so the harness marks them
**not an equal-rate cell**.

## Decode checksums

Peer checksums in the preflight match across the two hosts. syom's
planar checksums do not (every syom row). This run did not measure how
many LSBs that is. Encoder goldens above are the bitstream check.

## Linux LC ADTS again (2026-09-30)

Same harness binary, after the x86_64 IMDCT change (AVX stages inlined,
SSE2 pre/post rotate, no FMA). PCM checksum of `sine48.adts` is still
`0x8ee2d208ecbef564` (48000 Hz, 1 channel, 13312 samples). `taskset -c 0`,
governor `performance`. Load average 16.0 at start and 10.3 at end, so
this is not an idle machine. Raw rows:
`runs/2026-09-30-linux-x64-baseline.txt`.

| peer | median | bootstrap 95% |
|---|---:|---|
| syom | 94.4 µs | 86.4–138.3 |
| symphonia 0.6.1 | 143.4 µs | 143.3–143.7 |

Syom's interval sits below symphonia's. The syom samples step from about
165 µs down to about 86 µs; symphonia stays near 143 µs. rusty_aac and
oxideav-aac on this cell are about 239 ms and 217 ms. The 2026-09-29
row (syom 226 µs, symphonia 177 µs, overlapping intervals) is the earlier
tree.

## Cross-host PCM (2026-09-30)

`engine::pcm_host_probe` wrapping hash of `to_bits` (not the
`decode_cmp` FNV in the section above). rustc 1.97.1 on both hosts.
Darwin arm64, tree `~/src/syom-bench`.

Sine and KBD windows, scalefactor gains, and the 4/3-power table
matched before any edit and were left on their existing paths. The
2048-point IMDCT pre/post tables also matched across hosts under libm,
then both moved when those tables switched to `det_math::sincos`. The
2048 twiddle table and the four decode fixtures differed.
