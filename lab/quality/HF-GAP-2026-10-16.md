# Lecture HE v1 high band, 2026-10-16

Gate not passed. Encoder sources are unchanged from the tree this note
started on. `FORMANT_RATIO` is still `1.0e-2`. The cutoff rule in
`core_cutoff_hz` was not edited, and the crossover-reset trial in
`CORE_TUNE.md` was not repeated (that run left lecture LF at 31.5 /
32.2).

## What the column is

`syom_tune133 speech2` prints `HF err`: mean absolute 375 Hz band-level
error, 6.75–15.375 kHz, neutral ffmpeg 7.0.2 `pcm_f32le`, same
alignment as `CORE_TUNE.md`. Lower is closer to the source. It is not
an SNR. The same blocks' magnitude SNR above 6.75 kHz (the LF formula,
on that range) is about 0.4–2.8 dB for both encoders. Signed level
error is positive when the decode is hotter than the source.

Host: ffmpeg 7.0.2-static, `lab/fdk/fdk_driver` `encode-pcm` AOT 5,
fdk-aac 2.0.3, afterburner off. One core (`taskset -c 0`).

## Trial: unlimited low-rate limiter (not shipped)

`he_header`: for ≤ 24 kbps per channel, `bs_header_extra_2` and
`bs_limiter_gains = 3` (`limGain` 1e10 instead of the default +3 dB).
No cutoff change, no `FORMANT_RATIO` change. Same four-clip decode.
FDK rows did not move; syom:

| clip | actual k | SNR | LF | HF err | signed | HF mag SNR | vs gate |
|---|---:|---:|---:|---:|---:|---:|---|
| lecture | 39.1 | 36.0 | 36.6 | 22.5 | +20.6 | 1.3 | HF err and LF clear |
| lecture-m | 38.0 | 37.5 | 37.8 | 21.3 | +18.6 | 1.8 | HF err 21.3 < 23.6 |
| speech2 | 26.7 | 12.4 | 15.4 | 4.3 | −3.1 | 3.7 | HF err fell; LF 15.4 < 15.5 |
| speech2-m | 26.6 | 17.7 | 21.9 | 4.9 | −3.7 | 4.3 | HF err fell; LF 21.9 < 22.0 |

Per-band signed error on the first four 2048-sample blocks: with the
cap removed, speech2 sits mostly within ±8 dB, while lecture's upper
bands sit about +15 to +40 dB, the same shape FDK already has on
lecture. The shipped +3 dB limiter is what holds that lecture error at
17.6 instead of ~22. Removing it also reaches speech2's envelopes
(error 22.2 → 4.3) and misses both speech2 LF floors by 0.1 dB.

24 kbps/channel is the `he48` stereo rate, so this header would change
those bytes. It was not kept.

No other low-rate lever was measured. A global envelope boost would
push lecture's already-positive error up and, because `g_max` scales
with the target, would also feed speech2, whose error is not allowed
to fall. Those two directions conflict. The trial is reverted.
